# Creare predefiniti per uniformare il colore in una ripresa

Scoprite come conferire a un intero servizio fotografico un aspetto uniforme senza modificare ogni immagine singolarmente. In questo tutorial, scoprite come creare un predefinito di colore in Lightroom, quindi applicare quel color grading a un batch di immagini con azioni in blocco in Firefly. I file vengono restituiti nello stesso formato e con le stesse dimensioni in pixel degli originali. Guardate il tutorial e provatelo nella prossima ripresa.
