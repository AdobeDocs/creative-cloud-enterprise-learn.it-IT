# &#x200B;6. Personalizzare un modello

Ogni modello viene fornito con input di esempio e uno use case generico. Diventa un flusso di lavoro che funziona per *te* solo una volta che riflette le tue informazioni, le risorse e i risultati.

1. **Sostituisci gli input di esempio con una risorsa o un&#39;istruzione personalizzata.**
2. **Rinominare qualsiasi nodo o etichetta che utilizza ancora testo segnaposto.**
3. **Eseguire il grafico una volta, completamente, prima di fare affidamento sul risultato.**
4. **Modificare una variabile e rieseguirla**, in modo da poter vedere esattamente cosa controlla quel passaggio.
5. **Salvare la versione personalizzata con il proprio nome.**

Torna a [Introduzione a Firefly Graph](https://experienceleague.adobe.com/en/docs/creative-cloud-enterprise-learn/cce-learning-hub/fireflyoverview/firefly-graph/overview-firefly-graph).
